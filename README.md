# stm-markov-proxy (SMP)

Высокопроизводительный L7-балансировщик трафика и прокси-сервер на языке Haskell, спроектированный по канонам прагматичной промышленной разработки .

## Архитектурная триада проекта

1. **Инженерия (Flat Env):** Приложение использует плоский монадический стек `ReaderT Env IO`, полностью стираемый компилятором GHC при оптимизации. Настройки и рантайм-ссылки собраны в единый регистр.
2. **Рантайм (STM):** Балансировка Round-Robin реализована на базе Software Transactional Memory (`TVar`). Никаких пессимистичных мьютексов и блокировок — потоки работают через атомарные локальные черновики (TLog) в оперативной памяти.
3. **Математика (НАМ):** Маршрутизация и рерайтинг HTTP-заголовков/URL осуществляются с помощью детерминированного стримингового движка на базе Нормальных Алгоритмов Маркова (1951 г.) вместо ресурсоемких регулярных выражений.

## Текущий статус
- Развернут сетевой каркас диспетчера (IPv4 сокет на localhost).
- Настроена многопоточная обработка входящих соединений через легкие зеленые потоки GHC (`forkIO`).
- Журнал архитектурных решений ведется в формате LaTeX в директории `docs/adr/`.

## Ключевой архитектурный тезис

> **Build the proxy, don’t configure the proxy.**

SMP строит узкий proxy automaton под конкретное приложение, а не настраивает один универсальный runtime. Подробности: [Specialized Application Proxy Automaton](docs/specialized-application-proxy-automaton.md) и [ADR-0010](docs/adr/0010-build-the-proxy.md).
