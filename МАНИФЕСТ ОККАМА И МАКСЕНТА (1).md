# **📜 MANIFESTO: MaxEnt & Ockham’s Razor in Data Inference**

### **1\. Эпистемологический базис (Джейнс / Вассерман)**

> * **Принцип неопределенности:** Если форма распределения данных неизвестна, любое априорное предположение о ней (параметризация, сглаживание, подгонка под нормальность) — это необоснованная догадка.  
> * **Бритва Оккама:** Из всех гипотез, согласующихся с имеющимися данными, выбирается та, которая требует минимума скрытых предположений.  
> * **Принцип максимума энтропии (MaxEnt):** Рациональная вероятность — это распределение, которое максимизирует энтропию при заданных ограничениях. Без ограничений такое распределение является строго равномерным.

### **2\. Практический контракт (Эмпирический бутстрэп)**

> * **Честный хаос:** Для выборки объемом $N$ каждое наблюдение получает строго равный максентовский вес:  
>   $$p\_i \= \\frac{1}{N}$$  
> * **Комбинаторная строгость:** Генерация $B$ бутстрэп-реплик осуществляется путем равновероятного выбора элементов с возвращением (Monte Carlo sampling).  
> * **Функциональная чистота:** Модель не пытается «додумать» за природу то, чего нет в данных. Вся неопределенность отражается исключительно через эмпирический хаос повторных выборок.
