# ADR-0009: Побайтовый операционный автомат Вирта (FSM) для Zero-Copy изоляции URL

## Статус
**ACCEPTED** (Концепт утвержден, переходим к кодированию)

## Контекст
В рамках реализации двухавтоматной конфигурации L7-балансировщика (`ADR-0004`) необходимо изолировать строку URL из стартовой строки HTTP-запроса (Request Line). Классический подход с посимвольной сборкой буфера (накоплением новой строки в процессе чтения) порождает лишние аллокации в куче под обстрелом утилиты `wrk`. Требуется спроектировать энергоэффективный, быстрый автомат с регистрами памяти (Register Automaton), работающий со скоростью чистого Си.

## Решение
Утверждена архитектура побайтового автомата переходов по спецификации Вирта, работающая по принципу **Zero-Copy** (вычисление без копирования памяти). Вместо сборки новых строк автомат аккумулирует исключительно физические отступы (координаты) внутри исходного сетевого пакета.

### 1. Алгебраический тип-сумма фаз автомата
Для детерминированного контроля фаз времени объявляется строгое перечисление состояний:
- `Method` — фаза вычитки HTTP-метода (ищет первый пробел `0x20`).
- `URI` — фаза фиксации и прохода по байтам пути (ищет второй пробел `0x20`).
- `Version` — фаза вычитки версии протокола (ищет маркер конца строки `\r\n`).
- `Finish` — терминальная точка успешного завершения разбора.

### 2. Структура контекста автомата (ParserContext)
Контекст представляет собой тип-произведение (Record) и передается сквозь чистую хвостовую рекурсию, удерживая три ключевых регистра памяти:
- `currentState` — Текущий компас автомата (один из конструкторов фаз типа-суммы).
- `parsedOffsets` — Архивный кортеж или структура координат `(Int, Int)`, куда бережно записываются индекс начала URL (при переходе из `Method` в `URI`) и индекс конца URL (при переходе из `URI` в `Version`).
- `currentIndex` — Глобальный счетчик шагов процессора (`Int`), который увеличивается на единицу (`+1`) при каждом рекурсивном вызове, указывая на текущую позицию обрабатываемого байта `Word8`.

### Физика Zero-Copy извлечения
По достижении фазы `Finish`, автомат возвращает накопленные координаты начала и конца. Функция-драйвер с помощью легковесных библиотечных функций `B.take` и `B.drop` мгновенно вырезает URL из исходного массива `ByteString` за время $O(1)$. Рантайм GHC создает структуру-указатель, смотрящую в тот же кусок C-памяти в RAM, исключая копирование байт.

## Последствия
- **Плюсы:** Полное отсутствие аллокаций памяти при парсинге. Скорость выполнения эквивалентна арифметике указателей в Си. Кристальная чистота и тестируемость в REPL.
- **Минусы:** Требуется жесткая проверка на корректность входящих байт (защита от малформированных запросов без пробелов).
