# #4 — # Issue: Реализация побайтового операционного автомата Вирта (FSM) для изоляции URL


## Статус
**В РАБОТЕ** (Исполнитель: Кирилл)

## Задача
Разработать легковесный побайтовый конечный автомат (FSM) для разбора стартовой строки HTTP-запроса (Request Line) с целью точной изоляции URI до его передачи в вычислительное ядро `MarkovEngine`.

## Требования к реализации
1. **Конфигурация состояний:** Объявить алгебраический тип данных `data ParserState` с четырьмя детерминированными фазами: `Method`, `URI`, `Version`, `Finish`.
2. **Побайтовый конвейер:** Написать чистую функцию перехода, которая принимает текущее состояние, один входящий байт (`Word8`), и возвращает новое состояние.
3. **Критерии переходов:**
   - Из `Method` в `URI` по первому пробелу (`0x20`).
   - Из `URI` в `Version` по второму пробелу (`0x20`).
   - Из `Version` в `Finish` по маркеру конца строки (`\r\n`).
4. **Аккумуляция данных:** Обеспечить бережное накопление байт внутри конструктора состояния `URI` без промежуточных аллокаций.

**Связанная веха (Milestone):** `v0.1-mathematical-core`
