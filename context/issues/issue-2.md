# #2 — Математическое ядро движка

## Задача
Создать параметризованный движок Нормальных Алгоритмов Маркова для рерайтинга байт-строк `ByteString`.

## Требования
1. Внедрить типы данных `RuleType` и `MarkovRule` в кодовую базу.
2. Реализовать исполнителя одиночного шага `runMarkovStep` с возвратом кортежа состояния `(ByteString, Bool)`.
3. Написать рекурсивный диспетчер `runMarkov`, использующий лексическое замыкание для отката к полной колоде правил при успехе (`True`) и продвижения по хвосту при неудаче (`False`).
4. Полностью зачистить предупреждения компилятора GHC о затенении переменных (`Shadowing`) путем переименования аргументов внутреннего цикла.
5. Экспериментально внедрить декаррирование `uncurry` для оптимизации вызова исполнителя.
6. Верифицировать детерминизм через Emacs REPL на кастомных правилах подстановки.

**Связанная веха:** `v0.1-mathematical-core`
